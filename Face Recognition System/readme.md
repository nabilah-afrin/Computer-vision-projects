Face Recognition System using YOLOv3 and FaceNet
Developed a robust and accurate face recognition system using state-of-the-art deep learning models
Used YOLOv3 to detect faces in images and videos with high speed and precision
Used FaceNet to extract face embeddings and perform face verification and identification
Implemented the system in Python using TensorFlow, OpenCV, and NumPy libraries
